# Product Scope

## 目的

iPhoneで撮影した写真・動画をローカルPC上で読み込み、ブラウザで localhost を開いて編集し、最終的に動画として書き出せるローカル動画編集ソフト。

## 想定ユーザー

- 単一ユーザー / 単一マシン
- 自分で素材を取り込み、自分で編集して、自分で書き出す用途

## 対応OS

- コードはOS非依存
- テスト・サポートはLinuxのみ

## MVPでできること

### 入力

- `.jpg` / `.png` / `.heic` / `.heif`
- `.mp4` / `.mov`
- HEIC / HEVC は必須対応
- ProRes は入力許容（内部でproxy化）
- HDR素材は SDR に変換
- Live Photos / Dolby Vision は未対応

### 編集

- クリップの並べ替え
- 動画の前後トリム
- 静止画の挿入（デフォルト表示時間: 3秒）
- 1本のBGM追加（フェードなし、開始位置と長さの指定のみ）
- テロップ（背景帯つきテキスト、OS標準フォント固定）
- 回転補正
- 簡易クロップ
- 出力サイズ選択: 16:9 / 9:16 / 1:1
- Undo / Redo

### プレビュー

- proxy動画での再生（720p / H.264 / 30fps）
- シーク
- タイムライン表示
- サムネイル表示
- proxy生成完了前は静止サムネイルで操作可能

### 書き出し

- MP4 / H.264 + AAC
- 720p / 1080p
- SDR固定
- 元ファイルからエンコード（proxyではない）

## MVPでやらないこと

- マルチユーザー / クラウド同期
- Live Photos の完全対応
- HDR保持編集
- ProRes ネイティブ書き出し
- 高度な色補正
- 複数ビデオトラックの合成
- トランジション
- BGMフェードイン・アウト
- 音声波形編集
- AI機能
- モバイル対応
- WebSocket（ポーリングで代替）
