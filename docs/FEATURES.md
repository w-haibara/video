# 実装済み機能一覧

> 本ドキュメントは開発サーバ上での実操作（Playwright）およびソースコード調査に基づき作成。
> 確認日: 2026-03-14

## 技術スタック

| レイヤー | 技術 |
|---------|------|
| フロントエンド | React 19, Vite, React Router v7, TanStack Query v5 |
| バックエンド | Hono (HTTP フレームワーク), Bun ランタイム |
| 共有型定義 | TypeScript (strict mode) |
| メディア処理 | FFmpeg / FFprobe |
| テスト | Vitest + Playwright (ブラウザテスト), Storybook |
| 開発環境 | Concurrently, devcontainer 対応 |
