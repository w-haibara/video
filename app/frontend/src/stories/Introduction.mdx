# Video Editor

A browser-based video editing application.

## Architecture

- **React 19** with TypeScript
- **React Router** for client-side routing
- **TanStack Query** for server state management
- **Vite** for development and builds

## Pages

- **Home** — Project list and creation
- **Editor** — Timeline-based video editing with inspector, asset panel, and preview player
- **Job Log** — Background job monitoring

## Components

The component library includes timeline tracks, clips, playhead, ruler, preview player,
asset management, context menus, and project settings.
